# GrinchCafe

Локальная POS-система для кафе на Android: основной терминал, приложение официанта и админ-панель. Работает в одной Wi‑Fi сети без облачного бэкенда.

Сделано для реального заведения: столы, синхронизация заказов, печать ESC/POS (бар + кухня), импорт меню из Excel, отчёты по выручке.

## Приложения

| APK | Модуль | Назначение |
|-----|--------|------------|
| **GrinchCafe** | `app` | Основной терминал: столы, заказы, меню, печать, оплата, отчёты, HTTP-сервер `:8765` |
| **GrinchCafeWaiter** | `waiter` | Клиент официанта: столы, заказ, синхронизация с терминалом |
| **GrinchCafeAdmin** | `admin` | Клиент администратора: меню, отчёты, настройки |

## Возможности

- Управление столами и статусами (свободен / занят / резерв)
- Меню по разделам: обеденное, основное, бар
- Комплексный обед (суп + горячее + салат) одной позицией в чеке
- Импорт меню из `.xlsx` / CSV по разделам
- Синхронизация терминала с официантом и админом (~5 сек + вручную)
- Печать ESC/POS: USB-бар + сетевая кухня, фильтр категорий
- «Печать» (рабочий чек: старые → `+++` → новые) и «Полный чек» (гостевой)
- Отчёты по дням / месяцу / году, экспорт в файл

## Стек

- Java, Android (API 25+)
- SQLite
- Встроенный HTTP API на основном терминале
- Собственный парсер `.xlsx` для импорта меню

## Настройка перед внедрением

### Реквизиты на чеке

В `app/src/main/java/com/example/deviceinfo/util/ReceiptFormatter.java` укажите данные организации:

- название
- бренд (`GRINCHCAFE`)
- адрес
- УНП
- РН СККО

В репозитории стоят **плейсхолдеры** — замените их перед продакшеном.

### Сеть

1. Запустите основной терминал.
2. В «Настройках» посмотрите IP сервера.
3. В приложениях официанта и админа укажите **только IP** (порт `8765` подставляется автоматически).

### Меню

Загрузка из Excel: колонки `Категория`, `Название`, `Состав`, `Кол-во/Вес`, `Цена`.  
Импорт перезаписывает выбранный раздел целиком.

# GrinchCafe (English)

**Local Android POS system for cafes** — main terminal, waiter app, and admin client. Runs on a single Wi‑Fi network with no cloud backend.

Built for real venues: table management, order sync, ESC/POS printing (bar + kitchen), menu import from Excel, and sales reports.

## Apps

| APK | Module | Role |
|-----|--------|------|
| **GrinchCafe** | `app` | Main terminal: tables, orders, menu, printing, payments, reports, HTTP server on port `8765` |
| **GrinchCafeWaiter** | `waiter` | Waiter client: tables, orders, sync with terminal |
| **GrinchCafeAdmin** | `admin` | Admin client: menu, reports, connection settings |

## Features

- Table management with statuses (free / busy / reserved)
- Menu sections: lunch, main courses, bar
- Combo lunch (soup + hot dish + salad) as a single receipt line
- Menu import from `.xlsx` / CSV per section
- Sync between terminal, waiter, and admin (~5 s interval + manual refresh)
- ESC/POS printing: USB bar printer + network kitchen printer, category filters
- **Print** (kitchen workflow: old items → `+++` → new items) vs **Full receipt** (guest copy)
- Reports by day / month / year, export to file

## Tech stack

- Java, Android (API 25+)
- SQLite
- Embedded HTTP API on the main terminal
- Lightweight `.xlsx` parser for menu import (no heavy Excel libraries)

## Deployment

### Receipt header (business details)

Edit `app/src/main/java/com/example/deviceinfo/util/ReceiptFormatter.java`:

- legal name
- brand (`GRINCHCAFE`)
- address
- tax ID (UNP)
- cash register ID (RN SKKO)

The repository contains **placeholders** — replace them before production.

### Network setup

1. Launch the main terminal app.
2. Open **Settings** and note the server IP.
3. In waiter and admin apps, enter **IP only** (port `8765` is added automatically).

### Menu import

Excel columns: `Category`, `Name`, `Description`, `Qty/Weight`, `Price`.  
Import **replaces the entire selected section**.
