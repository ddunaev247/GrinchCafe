# GrinchCafe

**Local Android POS system for cafes** — main terminal, waiter app, and admin client. Runs on a single Wi‑Fi network with no cloud backend.

Built for real venues: table management, order sync, ESC/POS printing (bar + kitchen), menu import from Excel, and sales reports.

## Apps

| APK | Module | Role |
|-----|--------|------|
| **GrinchCafe** | `app` | Main terminal: tables, orders, menu, printing, payments, reports, HTTP server on port `8765` |
| **GrinchCafeWaiter** | `waiter` | Waiter client: tables, orders, sync with terminal |
| **GrinchCafeAdmin** | `admin` | Admin client: menu, reports, connection settings |

## Features

- Table management with statuses (free / busy / reserved)
- Menu sections: lunch, main courses, bar
- Combo lunch (soup + hot dish + salad) as a single receipt line
- Menu import from `.xlsx` / CSV per section
- Sync between terminal, waiter, and admin (~5 s interval + manual refresh)
- ESC/POS printing: USB bar printer + network kitchen printer, category filters
- **Print** (kitchen workflow: old items → `+++` → new items) vs **Full receipt** (guest copy)
- Reports by day / month / year, export to file

## Tech stack

- Java, Android (API 25+)
- SQLite
- Embedded HTTP API on the main terminal
- Lightweight `.xlsx` parser for menu import (no heavy Excel libraries)

## Build

### Requirements

- JDK 8
- Android SDK (API 25, Build Tools 25.0.3)
- `local.properties` with SDK path (auto-generated by Android Studio)

Example `local.properties` (**not committed**):

```properties
sdk.dir=C:/Users/<user>/AppData/Local/Android/Sdk
```

### Windows

```bat
build_apk.bat
```

Output APKs are copied to the project root:

- `GrinchCafe-debug.apk`
- `GrinchCafeWaiter-debug.apk`
- `GrinchCafeAdmin-debug.apk`

See [BUILD_APK.md](BUILD_APK.md) for details.

## Deployment

### Receipt header (business details)

Edit `app/src/main/java/com/example/deviceinfo/util/ReceiptFormatter.java`:

- legal name
- brand (`GRINCHCAFE`)
- address
- tax ID (UNP)
- cash register ID (RN SKKO)

The repository contains **placeholders** — replace them before production.

### Network setup

1. Launch the main terminal app.
2. Open **Settings** and note the server IP.
3. In waiter and admin apps, enter **IP only** (port `8765` is added automatically).

### Menu import

Excel columns: `Category`, `Name`, `Description`, `Qty/Weight`, `Price`.  
Import **replaces the entire selected section**.
